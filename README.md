# Пульс - лендинг фитнес-студии

Одностраничный сайт фитнес-студии в тёмном стиле. Демо-проект для портфолио, студия вымышленная.

**Живой сайт:** https://puls-fitness-landing.vercel.app

## Что внутри

- Первый экран с фото на всю ширину, оффером и цифрами
- Направления тренировок карточками с фото
- Расписание на неделю (на телефоне листается вбок)
- Блок персональных тренировок и абонементы с выделенным популярным тарифом
- Отзывы и частые вопросы
- Форма записи на пробную тренировку с проверкой полей и защитой от спам-ботов
- Адаптивная вёрстка для телефона, планшета и компьютера
- Оптимизированные изображения (WebP, разные размеры под экран)

## Стек

[Astro](https://astro.build) · [Tailwind CSS](https://tailwindcss.com) · деплой на [Vercel](https://vercel.com)

## Запуск

```sh
npm install
npm run dev     # http://localhost:4321
npm run build   # сборка в папку dist/
```

## Как адаптировать под клиента

Все тексты, расписание, абонементы, отзывы и вопросы лежат в `src/data/site.ts`, фото - в `src/assets/`, цвета и шрифты - в `src/styles/global.css`.
